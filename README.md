# Patrol Task based on spark robot

### This is an autonomous patrol, obstacle avoidance and color detection program executed on the Spark robot.

##  How to execute
### Ensure you are on a spark robot, or it may fail in the compilation process.

#### Terminal 1
source devel/setup.bash
roslaunch maze_runner spark_rtabmap_teleop.launch
#### Terminal 2
source devel/setup.bash
rosrun maze_runner success.py
